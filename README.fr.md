# Projet d'Exemple en JavaScript

Bienvenue dans ce dépôt d'exemple. Ce projet contient un script JavaScript simple qui sert de point de départ pour apprendre et expérimenter avec le langage.

## Description

Ce projet comprend un fichier `hello.js` qui affiche un message dans la console. Il est idéal pour ceux qui débutent avec JavaScript ou qui souhaitent explorer la structure de base d'un dépôt.

## Prérequis

- [Node.js](https://nodejs.org/) version 14 ou supérieure
- npm (inclus avec Node.js)

## Installation

Clonez le dépôt sur votre machine locale :

```bash
git clone https://github.com/krishna2700/dummy-repo.git
cd dummy-repo
```

## Utilisation

Exécutez le script principal avec la commande suivante :

```bash
node hello.js
```

Vous devriez voir dans la console :

```
Hello, World!
```
