# React ਦੀ ਜਾਣ-ਪਛਾਣ (ਪੰਜਾਬੀ ਵਿੱਚ)

## React ਕੀ ਹੈ?
React ਇੱਕ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਹੈ ਜੋ **ਮਾਡਿਊਲਰ**, **ਤੇਜ਼** ਅਤੇ **ਸਾਂਭਣਯੋਗ** ਤਰੀਕੇ ਨਾਲ ਯੂਜ਼ਰ ਇੰਟਰਫੇਸ (UI) ਬਣਾਉਣ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ। ਇਸਦੀ ਵਰਤੋਂ ਮੁੱਖ ਤੌਰ 'ਤੇ ਕੰਪੋਨੈਂਟ-ਅਧਾਰਿਤ ਆਧੁਨਿਕ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣ ਲਈ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

## React ਕਿਉਂ ਵਰਤੀਏ?
- **ਮੁੜ ਵਰਤੋਂ ਯੋਗ ਕੰਪੋਨੈਂਟ**: ਤੁਸੀਂ ਇੰਟਰਫੇਸ ਨੂੰ ਸੁਤੰਤਰ ਹਿੱਸਿਆਂ ਵਿੱਚ ਵੰਡ ਸਕਦੇ ਹੋ।
- **ਕੁਸ਼ਲ ਰੈਂਡਰਿੰਗ**: React DOM ਨੂੰ ਅਨੁਕੂਲਿਤ ਤਰੀਕੇ ਨਾਲ ਅਪਡੇਟ ਕਰਦਾ ਹੈ।
- **ਅਮੀਰ ਈਕੋਸਿਸਟਮ**: ਸੰਦ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਬਹੁਤ ਸਰਗਰਮ ਭਾਈਚਾਰਾ।
- **ਚੰਗੀ ਸਾਂਭ-ਸੰਭਾਲ**: ਵਧਦੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸਾਫ਼ ਆਰਕੀਟੈਕਚਰ।

## ਮੁੱਖ ਧਾਰਨਾਵਾਂ

### 1) ਕੰਪੋਨੈਂਟ
ਇੱਕ ਕੰਪੋਨੈਂਟ ਇੱਕ ਫੰਕਸ਼ਨ (ਜਾਂ ਕਲਾਸ) ਹੈ ਜੋ ਇੰਟਰਫੇਸ ਵਾਪਸ ਕਰਦਾ ਹੈ।

- **ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ**: ਦੂਜੇ ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਅੰਦਰ ਰੱਖਦਾ ਹੈ।
- **ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ**: ਪੇਰੈਂਟ ਤੋਂ ਡੇਟਾ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

### 2) JSX
JSX ਇੱਕ ਸਿੰਟੈਕਸ ਹੈ ਜੋ JavaScript ਵਿੱਚ HTML ਵਰਗਾ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

ਉਦਾਹਰਣ:
```jsx
const element = <h1>ਸਤਿ ਸ੍ਰੀ ਅਕਾਲ React</h1>;
```

### 3) Props
**Props** ਉਹ ਡੇਟਾ ਹੈ ਜੋ ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ ਤੋਂ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਨੂੰ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।
ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਇਹ ਸਿਰਫ਼ ਪੜ੍ਹਨ ਯੋਗ ਹੁੰਦੇ ਹਨ।

### 4) State
**State** ਕੰਪੋਨੈਂਟ ਦਾ ਅੰਦਰੂਨੀ ਡੇਟਾ ਹੈ ਜੋ ਸਮੇਂ ਦੇ ਨਾਲ ਬਦਲ ਸਕਦਾ ਹੈ (ਯੂਜ਼ਰ ਇੰਟਰੈਕਸ਼ਨ, API ਜਵਾਬ, ਆਦਿ)।

### 5) ਇੱਕ-ਦਿਸ਼ਾਵੀ ਡੇਟਾ ਵਹਾਅ
React ਵਿੱਚ, ਡੇਟਾ ਮੁੱਖ ਤੌਰ 'ਤੇ ਪੇਰੈਂਟ ਤੋਂ ਚਾਈਲਡ ਵੱਲ ਵਹਿੰਦਾ ਹੈ। ਇਹ ਮਾਡਲ ਐਪਲੀਕੇਸ਼ਨ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਵਧੇਰੇ ਅਨੁਮਾਨਯੋਗ ਬਣਾਉਂਦਾ ਹੈ।

## ਜ਼ਰੂਰੀ Hooks

### useState
ਫੰਕਸ਼ਨਲ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਲੋਕਲ ਸਟੇਟ ਮੈਨੇਜ ਕਰਨ ਦਿੰਦਾ ਹੈ।

### useEffect
ਰੈਂਡਰਿੰਗ ਤੋਂ ਬਾਅਦ ਸਾਈਡ ਇਫੈਕਟਸ (API ਕਾਲ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ, ਟਾਈਮਰ, ਆਦਿ) ਚਲਾਉਣ ਦਿੰਦਾ ਹੈ।

## ਸਾਧਾਰਨ ਉਦਾਹਰਣ

```jsx
import { useState } from 'react';

function ਕਾਊਂਟਰ() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>ਗਿਣਤੀ: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        ਵਧਾਓ
      </button>
    </div>
  );
}

export default ਕਾਊਂਟਰ;
```

## ਸ਼ੁਰੂਆਤ ਲਈ ਵਧੀਆ ਅਭਿਆਸ
- ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਛੋਟਾ ਅਤੇ ਪੜ੍ਹਨਯੋਗ ਰੱਖੋ।
- ਕੰਪੋਨੈਂਟਾਂ ਅਤੇ ਵੇਰੀਏਬਲਾਂ ਦੇ ਨਾਮ ਸਾਫ਼ ਰੱਖੋ।
- UI ਵਿੱਚ ਬਹੁਤ ਭਾਰੀ ਬਿਜ਼ਨਸ ਲੌਜਿਕ ਤੋਂ ਬਚੋ।
- ਮੁੜ ਵਰਤੋਂ ਯੋਗ ਹਿੱਸਿਆਂ ਨੂੰ ਵੱਖ ਕਰੋ।
- ਪ੍ਰੋਜੈਕਟ ਵਧਣ ਦੇ ਨਾਲ ਟੈਸਟ ਜੋੜਦੇ ਰਹੋ।

## ਸਿੱਟਾ
React ਆਧੁਨਿਕ ਅਤੇ ਮਜ਼ਬੂਤ ਇੰਟਰਫੇਸ ਬਣਾਉਣ ਲਈ ਇੱਕ ਵਧੀਆ ਸ਼ੁਰੂਆਤੀ ਬਿੰਦੂ ਹੈ। ਕੰਪੋਨੈਂਟ, props, state ਅਤੇ hooks ਵਿੱਚ ਮੁਹਾਰਤ ਹਾਸਲ ਕਰਕੇ, ਤੁਸੀਂ ਵਿਕਸਿਤ ਹੋਣ ਯੋਗ ਅਤੇ ਪੇਸ਼ੇਵਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾ ਸਕਦੇ ਹੋ।
