# React ਦੀ ਜਾਣ-ਪਛਾਣ (ਪੰਜਾਬੀ ਵਿੱਚ)

## React ਕੀ ਹੈ?
React ਇੱਕ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਹੈ ਜੋ **ਮਾਡਿਊਲਰ**, **ਤੇਜ਼** ਅਤੇ **ਰੱਖ-ਰਖਾਅ ਯੋਗ** ਤਰੀਕੇ ਨਾਲ ਯੂਜ਼ਰ ਇੰਟਰਫੇਸ (UI) ਬਣਾਉਣ ਲਈ ਬਣਾਈ ਗਈ ਹੈ। ਇਸਦੀ ਵਰਤੋਂ ਮੁੱਖ ਤੌਰ 'ਤੇ ਕੰਪੋਨੈਂਟ-ਆਧਾਰਿਤ ਆਧੁਨਿਕ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰਨ ਲਈ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

## React ਕਿਉਂ ਵਰਤੀਏ?
- **ਮੁੜ-ਵਰਤੋਂ ਯੋਗ ਕੰਪੋਨੈਂਟ**: ਇੰਟਰਫੇਸ ਨੂੰ ਸੁਤੰਤਰ ਬਲਾਕਾਂ ਵਿੱਚ ਵੰਡਿਆ ਜਾਂਦਾ ਹੈ।
- **ਕੁਸ਼ਲ ਰੈਂਡਰਿੰਗ**: React DOM ਨੂੰ ਅਨੁਕੂਲਿਤ ਤਰੀਕੇ ਨਾਲ ਅੱਪਡੇਟ ਕਰਦਾ ਹੈ।
- **ਭਰਪੂਰ ਈਕੋਸਿਸਟਮ**: ਸਾਧਨ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਬਹੁਤ ਸਰਗਰਮ ਕਮਿਊਨਿਟੀ।
- **ਵਧੀਆ ਰੱਖ-ਰਖਾਅ**: ਵਿਕਸਿਤ ਹੋ ਰਹੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸਪਸ਼ਟ ਆਰਕੀਟੈਕਚਰ।

## ਮੁੱਖ ਧਾਰਨਾਵਾਂ

### 1) ਕੰਪੋਨੈਂਟ
ਇੱਕ ਕੰਪੋਨੈਂਟ ਇੱਕ ਫੰਕਸ਼ਨ (ਜਾਂ ਕਲਾਸ) ਹੈ ਜੋ ਇੰਟਰਫੇਸ ਵਾਪਸ ਕਰਦਾ ਹੈ।

- **ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ**: ਦੂਜੇ ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ**: ਪੇਰੈਂਟ ਤੋਂ ਡੇਟਾ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

### 2) JSX
JSX ਇੱਕ ਸਿੰਟੈਕਸ ਹੈ ਜੋ JavaScript ਵਿੱਚ HTML ਵਰਗੀ ਦਿੱਖ ਦਿੰਦਾ ਹੈ।

ਉਦਾਹਰਨ:
```jsx
const element = <h1>ਸਤ ਸ੍ਰੀ ਅਕਾਲ React</h1>;
```

### 3) Props
**Props** ਉਹ ਡੇਟਾ ਹੈ ਜੋ ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ ਤੋਂ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਨੂੰ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।
ਇਹ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਸਿਰਫ਼ ਪੜ੍ਹਨ ਯੋਗ ਹੁੰਦਾ ਹੈ।

### 4) State
**State** ਕਿਸੇ ਕੰਪੋਨੈਂਟ ਦਾ ਅੰਦਰੂਨੀ ਡੇਟਾ ਹੈ ਜੋ ਸਮੇਂ ਦੇ ਨਾਲ ਬਦਲ ਸਕਦਾ ਹੈ (ਯੂਜ਼ਰ ਇੰਟਰੈਕਸ਼ਨ, API ਜਵਾਬ, ਆਦਿ)।

### 5) ਇੱਕ-ਦਿਸ਼ਾ ਡੇਟਾ ਪ੍ਰਵਾਹ
React ਵਿੱਚ, ਡੇਟਾ ਮੁੱਖ ਤੌਰ 'ਤੇ ਪੇਰੈਂਟ ਤੋਂ ਚਾਈਲਡ ਵੱਲ ਵਹਿੰਦਾ ਹੈ। ਇਹ ਮਾਡਲ ਐਪਲੀਕੇਸ਼ਨ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਵਧੇਰੇ ਅਨੁਮਾਨਯੋਗ ਬਣਾਉਂਦਾ ਹੈ।

## ਜ਼ਰੂਰੀ Hooks

### useState
ਫੰਕਸ਼ਨਲ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਸਥਾਨਕ ਸਟੇਟ ਦਾ ਪ੍ਰਬੰਧਨ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

### useEffect
ਰੈਂਡਰ ਤੋਂ ਬਾਅਦ ਸਾਈਡ ਇਫੈਕਟਸ (API ਕਾਲ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ, ਟਾਈਮਰ, ਆਦਿ) ਚਲਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ।

## ਛੋਟੀ ਉਦਾਹਰਨ

```jsx
import { useState } from 'react';

function ਕਾਊਂਟਰ() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>ਗਿਣਤੀ: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        ਵਧਾਓ
      </button>
    </div>
  );
}

export default ਕਾਊਂਟਰ;
```

## ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ ਵਧੀਆ ਅਭਿਆਸ
- ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਛੋਟਾ ਅਤੇ ਪੜ੍ਹਨ ਯੋਗ ਰੱਖੋ।
- ਕੰਪੋਨੈਂਟਾਂ ਅਤੇ ਵੇਰੀਏਬਲਾਂ ਨੂੰ ਸਪਸ਼ਟ ਨਾਮ ਦਿਓ।
- UI ਵਿੱਚ ਬਹੁਤ ਭਾਰੀ ਕਾਰੋਬਾਰੀ ਤਰਕ ਤੋਂ ਬਚੋ।
- ਮੁੜ-ਵਰਤੋਂ ਯੋਗ ਹਿੱਸਿਆਂ ਨੂੰ ਇਕੱਠਾ ਕਰੋ।
- ਪ੍ਰੋਜੈਕਟ ਵਧਣ ਦੇ ਨਾਲ-ਨਾਲ ਟੈਸਟ ਜੋੜੋ।

## ਸਿੱਟਾ
React ਆਧੁਨਿਕ ਅਤੇ ਮਜ਼ਬੂਤ ਇੰਟਰਫੇਸ ਬਣਾਉਣ ਲਈ ਇੱਕ ਵਧੀਆ ਸ਼ੁਰੂਆਤੀ ਬਿੰਦੂ ਹੈ। ਕੰਪੋਨੈਂਟਾਂ, props, state ਅਤੇ hooks ਵਿੱਚ ਮੁਹਾਰਤ ਹਾਸਲ ਕਰਕੇ, ਤੁਸੀਂ ਸਕੇਲੇਬਲ ਅਤੇ ਪੇਸ਼ੇਵਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰ ਸਕਦੇ ਹੋ।
