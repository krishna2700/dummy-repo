# React ਦੀ ਜਾਣ-ਪਛਾਣ (ਪੰਜਾਬੀ ਵਿੱਚ)

## React ਕੀ ਹੈ?
React ਇੱਕ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਹੈ ਜੋ ਯੂਜ਼ਰ ਇੰਟਰਫੇਸ (UI) ਬਣਾਉਣ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ। ਇਹ **ਮਾਡਿਊਲਰ**, **ਤੇਜ਼** ਅਤੇ **ਸੰਭਾਲਣਯੋਗ** ਤਰੀਕੇ ਨਾਲ ਕੰਮ ਕਰਦੀ ਹੈ। ਇਹ ਮੁੱਖ ਤੌਰ 'ਤੇ ਕੰਪੋਨੈਂਟ-ਅਧਾਰਤ ਆਧੁਨਿਕ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਹੈ।

## React ਕਿਉਂ ਵਰਤੀਏ?
- **ਮੁੜ-ਵਰਤੋਂਯੋਗ ਕੰਪੋਨੈਂਟ**: ਇੰਟਰਫੇਸ ਨੂੰ ਵੱਖ-ਵੱਖ ਸੁਤੰਤਰ ਬਲਾਕਾਂ ਵਿੱਚ ਵੰਡੋ।
- **ਕੁਸ਼ਲ ਰੈਂਡਰਿੰਗ**: React DOM ਨੂੰ ਅਨੁਕੂਲ ਤਰੀਕੇ ਨਾਲ ਅੱਪਡੇਟ ਕਰਦੀ ਹੈ।
- **ਅਮੀਰ ਈਕੋਸਿਸਟਮ**: ਟੂਲ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਬਹੁਤ ਸਰਗਰਮ ਕਮਿਊਨਿਟੀ।
- **ਚੰਗੀ ਸੰਭਾਲਯੋਗਤਾ**: ਵਧਦੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸਪੱਸ਼ਟ ਢਾਂਚਾ।

## ਮੁੱਖ ਸੰਕਲਪ

### 1) ਕੰਪੋਨੈਂਟ
ਕੰਪੋਨੈਂਟ ਇੱਕ ਫੰਕਸ਼ਨ (ਜਾਂ ਕਲਾਸ) ਹੈ ਜੋ ਇੰਟਰਫੇਸ ਵਾਪਸ ਕਰਦਾ ਹੈ।

- **ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ**: ਹੋਰ ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਰੱਖਦਾ ਹੈ।
- **ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ**: ਪੇਰੈਂਟ ਤੋਂ ਡੇਟਾ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

### 2) JSX
JSX ਇੱਕ ਸਿੰਟੈਕਸ ਹੈ ਜੋ JavaScript ਅੰਦਰ HTML ਵਰਗੀ ਦਿਸਦੀ ਹੈ।

ਉਦਾਹਰਨ:
```jsx
const element = <h1>ਸਤਿ ਸ੍ਰੀ ਅਕਾਲ React</h1>;
```

### 3) Props
**Props** ਉਹ ਡੇਟਾ ਹੈ ਜੋ ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ ਤੋਂ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਨੂੰ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।
ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਇਹ ਸਿਰਫ਼ ਪੜ੍ਹਨ ਲਈ ਹੁੰਦੇ ਹਨ।

### 4) State
**State** ਕੰਪੋਨੈਂਟ ਦਾ ਅੰਦਰੂਨੀ ਡੇਟਾ ਦਰਸਾਉਂਦਾ ਹੈ ਜੋ ਸਮੇਂ ਨਾਲ ਬਦਲ ਸਕਦਾ ਹੈ (ਯੂਜ਼ਰ ਇੰਟਰੈਕਸ਼ਨ, API ਜਵਾਬ, ਆਦਿ)।

### 5) ਇੱਕ-ਦਿਸ਼ਾਈ ਡੇਟਾ ਪ੍ਰਵਾਹ
React ਵਿੱਚ, ਡੇਟਾ ਮੁੱਖ ਤੌਰ 'ਤੇ ਪੇਰੈਂਟ ਤੋਂ ਚਾਈਲਡ ਵੱਲ ਵਹਿੰਦਾ ਹੈ। ਇਹ ਮਾਡਲ ਐਪਲੀਕੇਸ਼ਨ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਵਧੇਰੇ ਅਨੁਮਾਨਯੋਗ ਬਣਾਉਂਦਾ ਹੈ।

## ਜ਼ਰੂਰੀ Hooks

### useState
ਫੰਕਸ਼ਨਲ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਲੋਕਲ ਸਟੇਟ ਦਾ ਪ੍ਰਬੰਧਨ ਕਰਨ ਦਿੰਦਾ ਹੈ।

### useEffect
ਰੈਂਡਰ ਹੋਣ ਤੋਂ ਬਾਅਦ ਸਾਈਡ ਇਫੈਕਟ (API ਕਾਲਾਂ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ, ਟਾਈਮਰ, ਆਦਿ) ਚਲਾਉਣ ਦਿੰਦਾ ਹੈ।

## ਛੋਟੀ ਉਦਾਹਰਨ

```jsx
import { useState } from 'react';

function ਗਿਣਤੀਕਾਰ() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>ਗਿਣਤੀ: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        ਵਧਾਓ
      </button>
    </div>
  );
}

export default ਗਿਣਤੀਕਾਰ;
```

## ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਚੰਗੇ ਅਮਲ
- ਕੰਪੋਨੈਂਟ ਛੋਟੇ ਅਤੇ ਪੜ੍ਹਨਯੋਗ ਰੱਖੋ।
- ਕੰਪੋਨੈਂਟਾਂ ਅਤੇ ਵੇਰੀਏਬਲਾਂ ਦੇ ਨਾਂ ਸਪੱਸ਼ਟ ਰੱਖੋ।
- UI ਵਿੱਚ ਭਾਰੀ ਕਾਰੋਬਾਰੀ ਲੌਜਿਕ ਤੋਂ ਬਚੋ।
- ਦੁਹਰਾਉਣ ਵਾਲੇ ਹਿੱਸਿਆਂ ਨੂੰ ਮੁੜ-ਵਰਤੋਂਯੋਗ ਬਣਾਓ।
- ਪ੍ਰੋਜੈਕਟ ਵਧਣ ਨਾਲ ਟੈਸਟ ਜੋੜਦੇ ਰਹੋ।

## ਸਿੱਟਾ
React ਆਧੁਨਿਕ ਅਤੇ ਮਜ਼ਬੂਤ ਇੰਟਰਫੇਸ ਬਣਾਉਣ ਲਈ ਇੱਕ ਵਧੀਆ ਸ਼ੁਰੂਆਤੀ ਬਿੰਦੂ ਹੈ। ਕੰਪੋਨੈਂਟ, props, state ਅਤੇ hooks ਵਿੱਚ ਮੁਹਾਰਤ ਹਾਸਲ ਕਰਕੇ, ਤੁਸੀਂ ਸਕੇਲੇਬਲ ਅਤੇ ਪੇਸ਼ੇਵਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਤ ਕਰ ਸਕਦੇ ਹੋ।
