# React ਦੀ ਜਾਣ-ਪਛਾਣ

## React ਕੀ ਹੈ?
React ਇੱਕ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਹੈ ਜੋ **ਮਾਡਿਊਲਰ**, **ਤੇਜ਼** ਅਤੇ **ਸੰਭਾਲਣਯੋਗ** ਤਰੀਕੇ ਨਾਲ ਯੂਜ਼ਰ ਇੰਟਰਫੇਸ (UI) ਬਣਾਉਣ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ। ਇਸਦੀ ਵਰਤੋਂ ਮੁੱਖ ਤੌਰ 'ਤੇ ਕੰਪੋਨੈਂਟਾਂ 'ਤੇ ਆਧਾਰਿਤ ਆਧੁਨਿਕ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣ ਲਈ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

## React ਕਿਉਂ ਵਰਤੀਏ?
- **ਮੁੜ-ਵਰਤੋਂਯੋਗ ਕੰਪੋਨੈਂਟ**: ਤੁਸੀਂ ਇੰਟਰਫੇਸ ਨੂੰ ਸੁਤੰਤਰ ਹਿੱਸਿਆਂ ਵਿੱਚ ਵੰਡਦੇ ਹੋ।
- **ਕੁਸ਼ਲ ਰੈਂਡਰਿੰਗ**: React DOM ਨੂੰ ਅਨੁਕੂਲਿਤ ਤਰੀਕੇ ਨਾਲ ਅੱਪਡੇਟ ਕਰਦਾ ਹੈ।
- **ਅਮੀਰ ਈਕੋਸਿਸਟਮ**: ਟੂਲ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਬਹੁਤ ਸਰਗਰਮ ਕਮਿਊਨਿਟੀ।
- **ਚੰਗੀ ਸੰਭਾਲਯੋਗਤਾ**: ਵਧਦੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸਾਫ਼ ਆਰਕੀਟੈਕਚਰ।

## ਮੁੱਖ ਸੰਕਲਪ

### 1) ਕੰਪੋਨੈਂਟ
ਇੱਕ ਕੰਪੋਨੈਂਟ ਇੱਕ ਫੰਕਸ਼ਨ (ਜਾਂ ਕਲਾਸ) ਹੈ ਜੋ ਇੰਟਰਫੇਸ ਵਾਪਸ ਕਰਦਾ ਹੈ।

- **ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ**: ਦੂਜੇ ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
- **ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ**: ਪੇਰੈਂਟ ਤੋਂ ਡੇਟਾ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ।

### 2) JSX
JSX ਇੱਕ ਸਿੰਟੈਕਸ ਹੈ ਜੋ JavaScript ਵਿੱਚ HTML ਵਰਗਾ ਦਿਖਦਾ ਹੈ।

ਉਦਾਹਰਨ:
```jsx
const element = <h1>ਸਤ ਸ੍ਰੀ ਅਕਾਲ React</h1>;
```

### 3) Props
**Props** ਉਹ ਡੇਟਾ ਹੈ ਜੋ ਪੇਰੈਂਟ ਕੰਪੋਨੈਂਟ ਤੋਂ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਨੂੰ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।
ਇਹ ਚਾਈਲਡ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਸਿਰਫ਼ ਪੜ੍ਹਨਯੋਗ ਹੁੰਦੇ ਹਨ।

### 4) State
**State** ਕਿਸੇ ਕੰਪੋਨੈਂਟ ਦਾ ਅੰਦਰੂਨੀ ਡੇਟਾ ਹੈ ਜੋ ਸਮੇਂ ਦੇ ਨਾਲ ਬਦਲ ਸਕਦਾ ਹੈ (ਯੂਜ਼ਰ ਇੰਟਰੈਕਸ਼ਨ, API ਜਵਾਬ, ਆਦਿ)।

### 5) ਇੱਕ-ਦਿਸ਼ਾਵੀ ਡੇਟਾ ਪ੍ਰਵਾਹ
React ਵਿੱਚ, ਡੇਟਾ ਮੁੱਖ ਤੌਰ 'ਤੇ ਪੇਰੈਂਟ ਤੋਂ ਚਾਈਲਡ ਵੱਲ ਵਹਿੰਦਾ ਹੈ। ਇਹ ਮਾਡਲ ਐਪਲੀਕੇਸ਼ਨ ਦੇ ਵਿਵਹਾਰ ਨੂੰ ਵਧੇਰੇ ਅਨੁਮਾਨਯੋਗ ਬਣਾਉਂਦਾ ਹੈ।

## ਜ਼ਰੂਰੀ Hooks

### useState
ਫੰਕਸ਼ਨਲ ਕੰਪੋਨੈਂਟ ਵਿੱਚ ਲੋਕਲ ਸਟੇਟ ਪ੍ਰਬੰਧਿਤ ਕਰਨ ਦਿੰਦਾ ਹੈ।

### useEffect
ਰੈਂਡਰ ਤੋਂ ਬਾਅਦ ਸਾਈਡ ਇਫੈਕਟਸ (API ਕਾਲ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ, ਟਾਈਮਰ, ਆਦਿ) ਚਲਾਉਣ ਦਿੰਦਾ ਹੈ।

## ਛੋਟੀ ਉਦਾਹਰਨ

```jsx
import { useState } from 'react';

function ਕਾਊਂਟਰ() {
  const [ਗਿਣਤੀ, ਗਿਣਤੀਸੈੱਟ] = useState(0);

  return (
    <div>
      <p>ਕਾਊਂਟਰ: {ਗਿਣਤੀ}</p>
      <button onClick={() => ਗਿਣਤੀਸੈੱਟ(ਗਿਣਤੀ + 1)}>
        ਵਧਾਓ
      </button>
    </div>
  );
}

export default ਕਾਊਂਟਰ;
```

## ਸ਼ੁਰੂਆਤ ਲਈ ਵਧੀਆ ਅਭਿਆਸ
- ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਛੋਟਾ ਅਤੇ ਪੜ੍ਹਨਯੋਗ ਰੱਖੋ।
- ਕੰਪੋਨੈਂਟਾਂ ਅਤੇ ਵੇਰੀਏਬਲਾਂ ਦੇ ਨਾਮ ਸਾਫ਼ ਰੱਖੋ।
- UI ਵਿੱਚ ਬਹੁਤ ਜ਼ਿਆਦਾ ਬਿਜ਼ਨਸ ਲਾਜਿਕ ਤੋਂ ਬਚੋ।
- ਮੁੜ-ਵਰਤੋਂਯੋਗ ਹਿੱਸਿਆਂ ਨੂੰ ਵੱਖ ਕਰੋ।
- ਪ੍ਰੋਜੈਕਟ ਵਧਣ ਦੇ ਨਾਲ-ਨਾਲ ਟੈਸਟ ਜੋੜਦੇ ਰਹੋ।

## ਸਿੱਟਾ
React ਆਧੁਨਿਕ ਅਤੇ ਮਜ਼ਬੂਤ ਇੰਟਰਫੇਸ ਬਣਾਉਣ ਲਈ ਇੱਕ ਵਧੀਆ ਸ਼ੁਰੂਆਤੀ ਬਿੰਦੂ ਹੈ। ਕੰਪੋਨੈਂਟਾਂ, props, state ਅਤੇ hooks ਵਿੱਚ ਮੁਹਾਰਤ ਹਾਸਲ ਕਰਕੇ, ਤੁਸੀਂ ਸਕੇਲੇਬਲ ਅਤੇ ਪੇਸ਼ੇਵਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰ ਸਕਦੇ ਹੋ।
