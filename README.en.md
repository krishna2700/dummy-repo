# Project README

Welcome to this project! This repository contains educational materials and examples related to React and JavaScript.

## Overview

This project includes:
- **React Documentation**: Comprehensive guides about React concepts and best practices
- **Hello World Example**: A simple JavaScript file to get started
- **Multi-language Support**: Documentation available in multiple languages

## Project Files

- `hello.js` - A simple "Hello, World!" JavaScript example
- `README.md` - Main README (this file, in English)
- `README.fr.md` - Detailed introduction to React in French
- `README.es.md` - React introduction in Spanish

## Getting Started

### Running the Hello World Example

To run the hello.js file, use Node.js:

```bash
node hello.js
```

This will output: `Hello, World!`
