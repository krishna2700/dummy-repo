# agent-trial

## Description

**agent-trial** is a simple demo project used to test and showcase agent-based workflows. It contains basic files to demonstrate how automated agents can interact with a repository — creating files, making commits, and opening pull requests.

## Prerequisites

Before you begin, make sure you have the following installed:

- [Node.js](https://nodejs.org/) (version 14 or higher)
- [Git](https://git-scm.com/)
- A modern web browser

## Installation

1. Clone this repository:

```bash
git clone https://github.com/krishna2700/agent-trial.git
```

2. Navigate to the project directory:

```bash
cd agent-trial
```

3. No additional dependencies are required for this project.

## Usage

### Running the JavaScript file

```bash
node hello.js
```

### Opening the HTML file

Open `index.html` directly in your browser, or serve it with a simple HTTP server:

```bash
npx serve .
# or
python3 -m http.server 3000
```

Then visit `http://localhost:3000` in your browser.
