## What is React?

React is a JavaScript library for building user interfaces with a
**component-based** architecture. It is commonly used for modern web
applications.

## Key React Concepts (Very Short)

- **Components**: Small, reusable UI pieces.
- **JSX**: HTML-like syntax inside JavaScript.
- **Props**: Data passed from parent to child components.
- **State**: Internal data that can change over time.
- **Hooks**: Functions like `useState` and `useEffect` that add logic
  to function components.
