# Hello World Repository

A simple repository containing a Hello World JavaScript file.

## Contents

- `hello.js` — A minimal Node.js script that prints `Hello, World!` to the console.

## Usage

Run the script with Node.js:

```bash
node hello.js
```

### Expected output

```
Hello, World!
```

## Requirements

- [Node.js](https://nodejs.org/) (v14 or higher recommended)
