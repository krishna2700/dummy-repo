# Project Repository

This repository contains a simple JavaScript example and documentation about React.

## Contents

- **hello.js** - A basic JavaScript file that prints "Hello, World!" to the console.
- **README.md** - This file (English documentation).
- **README.es.md** - Spanish documentation.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v22 or higher recommended)

### Running the Example

```bash
node hello.js
```

Expected output:

```
Hello, World!
```
