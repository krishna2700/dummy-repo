# Hello World - JavaScript Project

A simple JavaScript project that prints "Hello, World!" to the console.

## Project Structure

```
/
├── hello.js        # Main entry point
├── README.md       # Project documentation (English)
└── README.es.md    # Project documentation (Spanish)
```

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Installation

No dependencies required. Clone or download the project files.

```bash
git clone <repository-url>
cd <project-directory>
```

### Running the Project

```bash
node hello.js
```

**Expected Output:**

```
Hello, World!
```

## Code Overview

### `hello.js`

```js
console.log('Hello, World!');
```

A minimal script that outputs a greeting message to the standard output.
