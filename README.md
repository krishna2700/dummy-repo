# Hello World Repository

A simple demonstration repository containing a basic "Hello, World!" JavaScript program.

## Contents

- `hello.js` - A simple JavaScript file that outputs "Hello, World!" to the console
- `README.es.md` - Spanish language README file

## Getting Started

### Prerequisites

- Node.js (version 22 or higher)

### Running the Program

To run the hello world program, execute:

```bash
node hello.js
```

This will output:
```
Hello, World!
```

## About

This repository serves as a simple starter project and demonstration of basic JavaScript execution.
