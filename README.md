# Project Repository

A simple JavaScript project repository.

## Contents

- `hello.js` — A basic JavaScript file that prints "Hello, World!" to the console.
- `README.es.md` — README in Spanish.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Running the Script

```bash
node hello.js
```

Expected output:

```
Hello, World!
```
