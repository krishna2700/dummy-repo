# Next.js Todo List App

---

## English

### Overview
A fully-featured Todo List application built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**. Tasks are color-coded by status and priority, and all data persists in your browser via `localStorage`.

### Features
- **Add tasks** with a title and priority level (Low / Medium / High)
- **Color-coded cards** by status:
  - Green — Completed tasks
  - Red — High-priority pending tasks (Urgent)
  - Amber — Medium-priority pending tasks (Pending)
  - Indigo — Low-priority pending tasks (Remaining)
- **Filter** tasks by All, Active, or Completed
- **Inline editing** — double-click any task to edit it
- **Clear completed** — remove all done tasks at once
- **Persistent storage** — todos survive page refresh via `localStorage`
- **Stats bar** showing Total, Remaining, and Done counts

### Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Tech Stack
- [Next.js 14](https://nextjs.org/) — React framework with App Router
- [TypeScript](https://www.typescriptlang.org/) — Type-safe JavaScript
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework

### Présentation
Une application de liste de tâches complète, construite avec **Next.js 14**, **TypeScript** et **Tailwind CSS**. Les tâches sont colorées selon leur statut et leur priorité, et toutes les données sont sauvegardées dans votre navigateur via `localStorage`.

- **Effacer les tâches terminées** — supprimer toutes les tâches accomplies en un clic
- **Stockage persistant** — les tâches survivent au rechargement de la page grâce à `localStorage`
